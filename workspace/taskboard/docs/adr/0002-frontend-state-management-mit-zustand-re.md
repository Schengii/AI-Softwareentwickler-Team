# Frontend State Management mit Zustand & React Router v6

Status: Angenommen

## Kontext

Anforderungen an SPA-State-Management für Kanban-Board, Auth und Zeiterfassungs-Widget.

## Entscheidung

Nutze Zustand für Auth, Tasks, Projects und TimeEntries sowie React Router v6 für deklaratives Client-Routing.

## Konsequenzen

Ermöglicht leichtgewichtige, performante Statusverwaltung ohne Redux-Boilerplate; Zustand bietet exzellente TypeScript-Integration und einfaches Re-rendering bei Teilmengen-Updates.

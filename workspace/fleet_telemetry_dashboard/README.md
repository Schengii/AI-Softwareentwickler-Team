# Telemetrie-Dashboard

Ein modernes, performantes Dashboard für die Flotten-Telemetrie, gebaut mit React, TypeScript und Tailwind CSS.

## Projektstruktur
- `src/components/`: Wiederverwendbare UI-Komponenten (Charts, Tabellen).
- `src/services/`: API-Integration (`/api/v1/`).
- `src/hooks/`: Custom Hooks für Daten-Polling und State-Management.

## Installation
```bash
npm install axios react-query recharts lucide-react
```

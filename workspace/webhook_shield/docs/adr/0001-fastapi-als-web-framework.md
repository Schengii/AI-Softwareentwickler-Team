# FastAPI als Web-Framework

Status: Angenommen

## Kontext

Wahl des Web-Frameworks für die Webhook-Verarbeitung.

## Entscheidung

Einsatz von FastAPI.

## Konsequenzen

Vorteile: Hohe Performance, native Async-Unterstützung, automatische OpenAPI-Dokumentation. Nachteile: Kleineres Ökosystem als Django. Alternative: Flask (zu simpel), Django (zu schwergewichtig).

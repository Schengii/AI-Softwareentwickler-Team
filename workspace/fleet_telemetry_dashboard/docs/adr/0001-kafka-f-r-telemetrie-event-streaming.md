# Kafka für Telemetrie-Event-Streaming

Status: Angenommen

## Kontext

Hohe Menge an Telemetrie-Daten erfordert skalierbare Ingestion.

## Entscheidung

Kafka als zentraler Message Broker.

## Konsequenzen

Höherer Durchsatz, persistente Speicherung der Events, komplexeres Setup (Zookeeper/Kafka).

# Tailwind CSS statt Bootstrap oder Custom CSS

Status: Angenommen

## Kontext

Wahl des CSS-Frameworks für das Dashboard. Alternativen: Bootstrap (schwerfälliger, Dark-Mode weniger intuitiv), reines CSS (hoher Wartungsaufwand).

## Entscheidung

Tailwind CSS für das Frontend-Styling.

## Konsequenzen

Vorteile: Sehr einfache Dark-Mode Implementierung, hochgradig anpassbar, kein CSS-Bloat. Nachteile: Erfordert Build-Prozess oder CDN-Einbindung.

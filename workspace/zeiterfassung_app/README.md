# ⏱️ Zeiterfassungs-Web-App

Eine moderne, performante Webanwendung zur digitalen Erfassung und Verwaltung von Arbeitszeiten für Teams und Unternehmen.

---

## 🛠️ Tech Stack

- **Backend:** Python 3.11+, FastAPI, SQLAlchemy (Async I/O), Pydantic v2
- **Datenbank:** PostgreSQL (Production) / SQLite Async (Development/Testing)
- **Authentifizierung:** OAuth2 mit JWT (JSON Web Tokens) & Passlib (bcrypt)
- **Frontend:** React, TypeScript, TailwindCSS
- **Dokumentation:** OpenAPI (Swagger UI & ReDoc)

---

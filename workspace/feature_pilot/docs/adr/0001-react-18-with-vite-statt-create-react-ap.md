# React 18 with Vite statt Create React App

Status: Angenommen

## Kontext

Frontend-Framework für das neue Fullstack-Projekt muss moderne Entwicklererfahrung, schnelle Hot-Module-Replacement und minimale Bundle-Größe bieten.

## Entscheidung

React 18 mit Vite wurde gewählt, weil Vite deutlich schnellere Entwicklungs-Startzeiten und HMR bietet, weniger Konfiguration benötigt und gut mit TypeScript harmoniert.

## Konsequenzen

Erfordert Vite-spezifische Build-Konfiguration; keine CRA-spezifischen Skripte. Team muss Vite-Plugins kennen. Zukunftssicher, da Vite von der Community stark unterstützt wird.

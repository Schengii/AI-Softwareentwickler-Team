# FastAPI statt Flask für das Backend

Status: Angenommen

## Kontext

Wahl des Web-Frameworks für das Backend. Alternativen: Flask, Django.

## Entscheidung

FastAPI, da es für moderne, performante APIs optimiert ist.

## Konsequenzen

Bessere Performance, native Async-Unterstützung, automatische OpenAPI-Dokumentation. Erfordert Einarbeitung in Pydantic.

# 💼 Job-Finder & Bewerbungsmanager (jobsuche-app)

Eine vollständige Anwendung für Fachinformatiker für Anwendungsentwicklung zur Jobsuche und Bewerbungsverwaltung.

## Features
- 📊 Dashboard mit Status-Metriken
- 🔍 Multi-Portal Jobsuche & Crawler (getInIT, StepStone, Indeed)
- 📋 Bewerbungs-Tracker mit Status & Notizen
- 📁 Dokumentenablage für Lebenslauf, Anschreiben & Zeugnisse
- ⚙️ Präferenzen & Suchfilter (Standort, Keywords)

## Installation & Start
```bash
pip install -r requirements.txt
streamlit run app.py
```

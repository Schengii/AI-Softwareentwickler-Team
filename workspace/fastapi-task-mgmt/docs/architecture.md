# Architektur: Task-Management-System

## Übersicht
Das System basiert auf einer modernen, asynchronen Architektur zur effizienten Verwaltung von Aufgaben mit Echtzeit-Synchronisation.

## Technologie-Stack
- **Backend:** FastAPI (Python 3.11+)
- **Datenbank:** SQLite mit SQLAlchemy 2.0 (async)
- **Synchronisation:** WebSockets für Echtzeit-Updates
- **Validierung:** Pydantic v2

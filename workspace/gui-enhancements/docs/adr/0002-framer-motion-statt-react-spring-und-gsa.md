# Framer Motion statt React Spring und GSAP für Animationsbibliothek

Status: Angenommen

## Kontext

Projekt benötigt Animationen, die leicht mit React komponierbar sind und Barrierefreiheit (Kontrast, Motion-Reduction) unterstützen.

## Entscheidung

Framer Motion wurde gewählt wegen deklarativer API, TypeScript-Unterstützung und einfacher Integration in React-Komponenten.

## Konsequenzen

Framer Motion bietet deklarative Animationen, enge Integration mit React, gute Performance und unterstützt WCAG-konforme Motion. Weniger Lernkurve als GSAP, aber weniger physikbasierte Kontrolle als React Spring.

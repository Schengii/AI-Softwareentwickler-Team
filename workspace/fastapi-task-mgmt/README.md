# Task Management System

## Kurzbeschreibung
Ein performantes Task-Management-System mit REST-API und Echtzeit-Updates via WebSockets.

## Voraussetzungen
- Python 3.11+
- `pip`

## Installation
1. Repository klonen: `git clone <url>`
2. Virtuelle Umgebung erstellen: `python -m venv venv && source venv/bin/activate`
3. Abhängigkeiten installieren: `pip install -r requirements.txt`

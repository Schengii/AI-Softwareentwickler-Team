# 📊 FastAPI Health-Monitor & Live-Dashboard

Ein hochperformantes, asynchrones Überwachungssystem für Web-Dienste und APIs mit einem integrierten React Live-Dashboard, WebSocket-Echtzeit-Metrics, SQLite-Persistenz und flexibler Alerting-Logik.

---

## 🚀 Features

- **Asynchrones Servicemonitoring:** Regelmäßige HTTP/HTTPS-Health-Checks mit konfigurierbaren Intervallen und Timeouts.
- **Echtzeit Live-Dashboard:** React 18 SPA mit Tailwind CSS (Dark Mode) und Chart.js Visualisierung.
- **WebSocket-Feeds:** Latenzfreie Übertragung von Systemmetriken und Statusänderungen an verbundene Dashboard-Clients.
- **Automatische API-Doku:** Swagger UI (`/docs`) & ReDoc (`/redoc`) powered by FastAPI & Pydantic.
- **SQLite & SQLAlchemy Async:** Effiziente Speicherung von historischen Uptime-Daten und Metriken.

---

## 📋 Voraussetzungen

- **Python:** 3.11 oder neuer
- **Virtuelle Umgebung:** `venv` empfohlen

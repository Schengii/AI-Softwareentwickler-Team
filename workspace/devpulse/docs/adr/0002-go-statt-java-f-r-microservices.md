# Go statt Java für Microservices

Status: Angenommen

## Kontext

Microservice-Implementierung benötigt geringe Latenz, einfache Deployment-Größe und gute Concurrency-Unterstützung.

## Entscheidung

Go

## Konsequenzen

Schnelle Compile-Zeiten, statisch verlinkte Binaries, geringerer Ressourcenverbrauch. Erfordert Go-Expertise, weniger Bibliotheken als Java.

# React statt Vue 3 und Svelte für UI-Framework

Status: Angenommen

## Kontext

Projekt benötigt ein UI-Framework mit starkem TypeScript-Support, großer Community und guter Bundle-Size für modulare Komponenten und Animationen.

## Entscheidung

React wurde gewählt wegen exzellentem TypeScript-Ökosystem, breiter Bibliotheksunterstützung (z.B. Framer Motion) und stabiler Community.

## Konsequenzen

Ermöglicht Nutzung von React-Hooks, breites Entwicklerwissen, aber größere Grundgröße gegenüber Svelte. Migration zu anderen Frameworks später aufwändig.

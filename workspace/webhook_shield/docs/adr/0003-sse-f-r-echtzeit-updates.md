# SSE für Echtzeit-Updates

Status: Angenommen

## Kontext

Wahl der Technologie für Echtzeit-Updates im Frontend.

## Entscheidung

Einsatz von Server-Sent Events (SSE).

## Konsequenzen

Vorteile: Einfach zu implementieren, HTTP-basiert, firewall-freundlich. Nachteile: Unidirektional. Alternative: WebSockets (bidirektional, aber komplexer im State-Management).

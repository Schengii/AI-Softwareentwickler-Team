# SentinelProxy

SentinelProxy ist ein resilienter API-Gateway-Dienst, der auf FastAPI und HTTPX basiert. Er dient als intelligenter Proxy für Upstream-Services und bietet integrierte Mechanismen zur Fehlerbehandlung und Webhook-Verarbeitung.

# Sicherheitsrichtlinie / Security Policy

## Sicherheitslücke melden / Reporting a vulnerability

Bitte melde Sicherheitslücken **nicht** als öffentliches Issue, sondern vertraulich über
[GitHub Security Advisories](../../security/advisories/new) ("Report a vulnerability").
Please do **not** open a public issue; use the private advisory form above instead.

Ich antworte in der Regel innerhalb weniger Tage. / I usually respond within a few days.

## Unterstützte Versionen / Supported versions

Es wird jeweils der aktuelle Stand des `main`-Branches gepflegt.
Only the current state of the `main` branch is maintained.

# FastAPI statt Django

Status: Angenommen

## Kontext

Wahl des Web-Frameworks für die SaaS-Plattform. Alternative: Django (monolithisch, schwerfälliger).

## Entscheidung

Verwendung von FastAPI für das Backend.

## Konsequenzen

Schnellere I/O-Operationen, native Unterstützung für moderne Python-Features, jedoch weniger "Batteries-included" als Django.

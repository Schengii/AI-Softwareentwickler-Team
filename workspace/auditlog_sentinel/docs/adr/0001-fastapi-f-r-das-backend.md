# FastAPI für das Backend

Status: Angenommen

## Kontext

Wahl des Web-Frameworks für das Backend. Alternativen: Flask, Django.

## Entscheidung

FastAPI wurde gewählt aufgrund der asynchronen Fähigkeiten und der exzellenten Developer Experience für API-first Architekturen.

## Konsequenzen

Höhere Performance bei I/O-lastigen Aufgaben, native Typisierung durch Pydantic, automatische OpenAPI-Dokumentation. Erfordert asynchrones Datenbank-Design.

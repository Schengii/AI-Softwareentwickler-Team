# FastAPI statt Flask oder Django

Status: Angenommen

## Kontext

Wahl des Web-Frameworks für den Log-Aggregator. Alternativen: Flask (zu simpel/synchron), Django (zu schwergewichtig/Overkill).

## Entscheidung

FastAPI als Web-Framework.

## Konsequenzen

Vorteile: Hohe Performance durch AsyncIO, automatische OpenAPI-Generierung, moderne Typ-Validierung. Nachteile: Kleineres Ökosystem als Django.

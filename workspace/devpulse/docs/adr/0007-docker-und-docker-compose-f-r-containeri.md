# Docker und Docker Compose für Containerisierung

Status: Angenommen

## Kontext

Das Projekt benötigt eine konsistente, reproduzierbare Umgebung für Entwicklung und Produktion. Docker bietet hierfür den Industriestandard.

## Entscheidung

Verwendung von Docker und Docker Compose für die Containerisierung der Microservices (Backend, Frontend, DB).

## Konsequenzen

Einfachere Entwicklung und Deployment durch standardisierte Container. Erfordert Pflege der Dockerfiles und CI/CD-Pipeline. Erhöht die Komplexität der lokalen Entwicklungsumgebung leicht.

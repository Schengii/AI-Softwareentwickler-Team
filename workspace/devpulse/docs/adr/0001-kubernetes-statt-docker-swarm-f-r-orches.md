# Kubernetes statt Docker Swarm für Orchestrierung

Status: Angenommen

## Kontext

Die Plattform muss hoch skalierbar, ausfallsicher und leicht zu verwalten sein, mit Unterstützung für automatisches Rollout und Service-Discovery.

## Entscheidung

Kubernetes

## Konsequenzen

Ermöglicht deklarative Deployments, Auto-Scaling, Self-Healing. Erhöhte Komplexität und Lernkurve, erfordert Cloud‑Native Infrastruktur.
